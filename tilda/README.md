# Рум-сервис «Берёза» — модификация корзины Tilda

Файл: **`footer-roomservice-cart.html`** — готовый блок (CSS + JS) для вставки в футер сайта
[roomservice-bereza.ru](https://roomservice-bereza.ru/).

## Что делает

| Правило ТЗ | Реализация |
|---|---|
| Завтраки: слоты 8:00 … 10:00 через полчаса, кухне 30 мин | Слот доступен, пока до него ≥ 30 мин. В 7:31 слот 8:00 уже закрыт, доступны 8:30 и далее |
| Остальные категории: 13:00 … 22:00 через полчаса, кухне 60 мин | В 12:31 слоты 13:00 и 13:30 закрыты, доступен 14:00 и далее. Утренние и дневные слоты разделены подписями «Утро» и «День» |
| Обслуживание 10% | Отдельной строкой после суммы заказа. Кладётся в штатное поле Tilda `tcart.delivery`, поэтому входит в итог, в письмо заказа и в сумму к оплате. Отключается через `CFG.service.percent = 0` |
| Сырники и запеканка — и на завтрак, и днём | Лежат в разделе «Завтраки», но подаются в оба окна: не вызывают конфликта, подстраиваются под остальной заказ, а в одиночку дают оба окна |
| Корзина обновляется онлайн | Пересчёт каждую секунду: слоты гаснут сами, выбранное «сгоревшее» время снимается с предупреждением |
| Завтраки нельзя смешивать с другими категориями | Ошибка показывается **в момент добавления** товара (товар в корзину не попадает) + баннер в корзине с кнопками «Оставить только завтраки» / «Оставить основное меню» + блокировка кнопки «ЗАКАЗАТЬ» |
| Время московское | Часовой пояс `Europe/Moscow` через `Intl`, у часов в корзине подпись «Ростов-на-Дону» (`CFG.city`). Плюс сверка часов гостя с часами сервера (HEAD-запрос, заголовок `Date`) — сбитые часы на телефоне не ломают логику |
| Кофе, чай и напитки — к любому заказу | Нейтральная категория `CFG.neutral`: сочетается и с завтраками, и с основным меню, в любом количестве. Заказ из одних напитков можно принести в оба рабочих окна — 8:00–10:00 и 13:00–22:00 |
| Время на приготовление гостю не показывается | Запас на кухню только закрывает ближайшие слоты; в текстах интерфейса о нём ничего нет |
| Шрифт Jost | `font-family:'Jost',Arial,sans-serif` — шрифт уже подключён на сайте |

Дополнительно:

* Выбор даты — «Сегодня» / «Завтра». Если на сегодня приём уже закрыт, дата переключается автоматически.
* Выбранные дата и время записываются в **штатные поля Tilda** `data_dostavki` (ДД-ММ-ГГГГ) и
  `vremya_dostavki` (ЧЧ:ММ) — формат заказа в почте/CRM не меняется. Родные поля скрываются,
  чтобы гость не мог ввести произвольное время.
* Кнопка «ЗАКАЗАТЬ» гасится, пока заказ нельзя оформить; при клике объясняется причина.
* Мобильная вёрстка, поддержка клавиатуры, `prefers-reduced-motion`, `aria-live` для ошибок.

## Демонстрация

`demo.html` — интерактивный предпросмотр (открывается в браузере локально или по ссылке-артефакту).
Внутри работает тот же код, что уходит на сайт: можно перевести часы на 7:31 или 12:31,
собрать заказ, попробовать смешать завтрак с основным меню и посмотреть, что уходит в поля Tilda.

## Установка

1. Открыть **Настройки сайта → Ещё → HTML-код для вставки внутрь BODY** (перед `</body>`).
2. Вставить всё содержимое `footer-roomservice-cart.html`.
3. Сохранить и **опубликовать все страницы** (важно: код должен попасть на страницы с корзиной).

Альтернатива: блок **T123 «HTML»** в футере — эффект тот же.
В режиме редактора/превью Tilda скрипт сам себя отключает, чтобы не мешать работе в конструкторе.

## Как настроить категории

Завтраки — точный список, напитки — список плюс ключевые слова, всё остальное считается основным меню.

```js
CFG.anytime.ids  / .slugs / .titles    // подаются и утром, и днём (сырники, запеканка)
CFG.breakfast.ids / .slugs / .titles   // завтраки
CFG.neutral.ids  / .slugs / .titles    // кофе, чай, напитки — сочетаются с любым заказом
CFG.neutral.keywords                   // страховка по словам: «кофе», «чай», «морс», …
CFG.city                               // подпись у часов в корзине
CFG.service.percent                    // обслуживание, % от суммы заказа (0 — выключить)
```

Ключевые слова ищутся по целому слову: «Кофейный чизкейк» и «Чайная колбаса» напитками не считаются.
Напиток внутри сета («Русский завтрак — Латте») остаётся завтраком: завтраки проверяются первыми.

## Как добавить новый завтрак в меню

В блоке `CFG.breakfast` (в начале скрипта) есть три списка. Достаточно дописать **один** из них:

```js
ids:    ['142718970583', ...]   // число из ссылки /tproduct/142718970583-...
slugs:  ['shakshuka', ...]      // текстовая часть ссылки
titles: ['Шакшука', ...]        // точное название товара
```

Модификации товара (напиток, топпинг, база) определять не нужно — они наследуют категорию
родительского товара по ссылке и названию.

Есть и страховка: всё, где в названии или ссылке встречается «завтрак»/«zavtrak»,
считается завтраком автоматически (`CFG.breakfast.keywords`).

## Как изменить время работы

```js
CFG.menus.breakfast.slots = ['08:00','08:30','09:00','09:30','10:00'];
CFG.menus.breakfast.lead  = 30;   // минут на приготовление
CFG.menus.main.slots      = ['13:00', ... ,'22:00'];
CFG.menus.main.lead       = 60;
CFG.daysForward           = 1;    // 1 = «Сегодня» + «Завтра», 2 = ещё и «Послезавтра»
```

## Если корзина ведёт себя неожиданно

В консоли браузера на сайте выполнить `RSB.state()` — покажет московское время, поправку часов,
счётчик корзины Tilda, что скрипт считает содержимым корзины и как классифицировал каждую позицию.
`RSB.clear()` полностью очищает корзину.

Блокировка добавления устроена «безопасно»: если состояние корзины вызывает сомнения
(объект Tilda пуст, содержит мусорные записи или счётчик корзины показывает ноль) — товар
пропускается, а конфликт всё равно поймает баннер в корзине. Гость не может упереться в ошибку
при пустой корзине. В самом уведомлении есть кнопка «Очистить корзину и добавить».
