# Рум-сервис «Берёза» — модификация корзины Tilda

Файл: **`footer-roomservice-cart.html`** — готовый блок (CSS + JS) для вставки в футер сайта
[roomservice-bereza.ru](https://roomservice-bereza.ru/).

## Что делает

| Правило ТЗ | Реализация |
|---|---|
| Завтраки: слоты 8:00 / 8:30 / 9:00 / 9:30 / 10:00, кухне 30 мин | Слот доступен, пока до него ≥ 30 мин. В 7:31 МСК слот 8:00 уже закрыт, доступны 8:30 и далее |
| Остальные категории: 13:00–22:00 по часам, кухне 60 мин | В 12:31 МСК слот 13:00 закрыт, доступен 14:00 и далее |
| Корзина обновляется онлайн | Пересчёт каждую секунду: слоты гаснут сами, выбранное «сгоревшее» время снимается с предупреждением |
| Завтраки нельзя смешивать с другими категориями | Ошибка показывается **в момент добавления** товара (товар в корзину не попадает) + баннер в корзине с кнопками «Оставить только завтраки» / «Оставить основное меню» + блокировка кнопки «ЗАКАЗАТЬ» |
| Время московское | Часовой пояс `Europe/Moscow` через `Intl`, плюс сверка часов гостя с часами сервера (HEAD-запрос, заголовок `Date`) — сбитые часы на телефоне не ломают логику |
| Шрифт Jost | `font-family:'Jost',Arial,sans-serif` — шрифт уже подключён на сайте |

Дополнительно:

* Выбор даты — «Сегодня» / «Завтра». Если на сегодня приём уже закрыт, дата переключается автоматически.
* Выбранные дата и время записываются в **штатные поля Tilda** `data_dostavki` (ДД-ММ-ГГГГ) и
  `vremya_dostavki` (ЧЧ:ММ) — формат заказа в почте/CRM не меняется. Родные поля скрываются,
  чтобы гость не мог ввести произвольное время.
* Кнопка «ЗАКАЗАТЬ» гасится, пока заказ нельзя оформить; при клике объясняется причина.
* Мобильная вёрстка, поддержка клавиатуры, `prefers-reduced-motion`, `aria-live` для ошибок.

## Установка

1. Открыть **Настройки сайта → Ещё → HTML-код для вставки внутрь BODY** (перед `</body>`).
2. Вставить всё содержимое `footer-roomservice-cart.html`.
3. Сохранить и **опубликовать все страницы** (важно: код должен попасть на страницы с корзиной).

Альтернатива: блок **T123 «HTML»** в футере — эффект тот же.
В режиме редактора/превью Tilda скрипт сам себя отключает, чтобы не мешать работе в конструкторе.

## Как добавить новый завтрак в меню

В блоке `CFG.breakfast` (в начале скрипта) есть три списка. Достаточно дописать **один** из них:

```js
ids:    ['142718970583', ...]   // число из ссылки /tproduct/142718970583-...
slugs:  ['shakshuka', ...]      // текстовая часть ссылки
titles: ['Шакшука', ...]        // точное название товара
```

Модификации товара (напиток, топпинг, база) определять не нужно — они наследуют категорию
родительского товара по ссылке и названию.

Есть и страховка: всё, где в названии или ссылке встречается «завтрак»/«zavtrak»,
считается завтраком автоматически (`CFG.breakfast.keywords`).

## Как изменить время работы

```js
CFG.menus.breakfast.slots = ['08:00','08:30','09:00','09:30','10:00'];
CFG.menus.breakfast.lead  = 30;   // минут на приготовление
CFG.menus.main.slots      = ['13:00', ... ,'22:00'];
CFG.menus.main.lead       = 60;
CFG.daysForward           = 1;    // 1 = «Сегодня» + «Завтра», 2 = ещё и «Послезавтра»
```
