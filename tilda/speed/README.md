# Ускорение загрузки roomservice-bereza.ru

Полный отчёт с планом работ — `report.html` (открывается в браузере).

## Файлы

| Файл | Куда | Что делает |
|---|---|---|
| `head-speed.html` | Настройки сайта → Ещё → **HTML-код внутрь HEAD** | Заранее открывает соединения с `store.tildaapi.com`, `static.tildacdn.com`, `optim.tildacdn.com`, `ws/neo.tildacdn.com` и шрифтами. Дописывает `display=swap` к Google Fonts, чтобы текст был виден сразу, а не через 3 секунды |
| `perf-probe.html` | Настройки сайта → Ещё → **HTML-код внутрь BODY** | Измеритель скорости. Адрес `?speed=1` показывает панель с замерами, `?speed=0` скрывает. В консоли — `TSPEED.report()` с разбором по доменам |
| `htaccess-optimized` | корень сайта, **только если это свой хостинг** | Сжатие (brotli/gzip), кэш на год, отдача WebP. Прежние правила сохранены |
| `optimize-photos.py` | запускается у вас | Из выгрузки магазина делает лёгкие WebP с именами по названиям блюд + отчёт + файл для обратного импорта |
| `../images-webp/` | готовые файлы | Все 12 картинок сайта в WebP: 4,66 МБ → 0,82 МБ. Подписаны, есть `install.sh` |

## Как понять, нужен ли htaccess

Открыть сайт → правая кнопка → «Исходный код страницы» → найти `tilda-scripts-3.0`:

* `src="js/tilda-scripts-3.0.min.js"` — сайт отдаётся с вашего хостинга, файл нужен;
* `src="https://static.tildacdn.com/js/..."` — сайт на хостинге Tilda, сжатие и кэш там уже есть.

## Как измерять

1. `https://roomservice-bereza.ru/?speed=1` — панель в правом нижнем углу, скриншот.
2. Включить VPN, обновить страницу — второй скриншот.
3. То же самое с телефона по мобильному интернету.
4. После каждой правки повторить в тех же условиях.

Ключевая строка панели — **Каталог**: сколько прошло до появления первой карточки блюда.

## Фотографии блюд

**Простой способ.** Положите выгрузку товаров (CSV) в одну папку с файлами
`optimize-photos.py` и `run-windows.bat` (или `run-mac.command`) — и запустите лаунчер
двойным щелчком. Он сам найдёт выгрузку, доустановит библиотеку и всё обработает.
На Mac при первом запуске может понадобиться правая кнопка → «Открыть» → «Открыть».

Не кладите папку в OneDrive: файлы там бывают «только в облаке», и скрипт их не увидит.

`run-windows.bat` намеренно написан **без единой русской буквы**: cmd.exe читает bat-файл
в кодировке OEM и на кириллице ломает разбор команд. Вся русская речь — внутри
Python-скрипта, там она отображается правильно. При правках bat-файла это надо сохранить.

**Через терминал.**

```bash
pip install pillow
python3 optimize-photos.py store.csv          # выгрузка Tilda → Магазин → Товары → Экспорт
python3 optimize-photos.py store.csv --limit 3  # сначала проверить на трёх товарах
python3 optimize-photos.py --auto              # сам найдёт выгрузку рядом с собой
```

Скрипт ничего не меняет на сайте: он только создаёт папку `photos/` рядом с собой.
Нужен интернет — фотографии скачиваются с серверов Tilda; если включён VPN, через который
`static.tildacdn.com` недоступен, его надо выключить на время работы скрипта.

Скачает каждое фото, уменьшит до 1600 точек, сожмёт в WebP и назовёт по блюду
(`shakshuka.webp`). В папке `photos/` появятся `SPISOK.csv` (что во что превратилось)
и `IMPORT.csv` (выгрузка с новыми путями для обратного импорта в Tilda).

Полезно знать: каталог Tilda подставляет в карточку **исходный файл без уменьшения** —
ресайз применяется только к размытой заглушке в 20 точек. Поэтому размер исходника важен.

## Главное из отчёта

1. Фотографии блюд в PNG — самая тяжёлая часть сайта, перезалить в WebP.
2. Картинки сайта уже сжаты: 4,66 МБ → 0,82 МБ (папка `images-webp/`).
3. Шрифт Jost прячет текст до трёх секунд — лечится кодом в HEAD, правильно решается своим шрифтом.
4. Нет счётчика посещаемости — скорость никто не измеряет.
5. Дублирования каталога больше нет — проверено по выгрузке от 2 сентября.
